## 🗣️ Hinglish Explanation

Yeh ek chhota **orientation/promo lecture** hai — koi technical content nahi. Ed sabse common question ka jawab deta hai: *"Tumhare courses ek dusre se kaise fit hote hain, kis order mein karu?"*

Ed ke curriculum mein **6 courses** hain:

1. **AI Builder** — no-code agents aur voice agents banana (n8n + 11Labs jaise tools se). Ek bhi line code likhe bina business ke liye agents.
2. **AI Coder** — Claude Code aur dusre coding agents se software/products banana, astonishing speed se.
3. **AI Leader** — AI projects deliver karna, business transformation, even apna AI business start karna. Startup ho ya Fortune 500 — commercial impact.
4. **AI Engineer Core Track** — LLMs & APIs, open-source LLMs, RAG, fine-tuning. (LLM Engineering course.)
5. **AI Engineer Agentic Track** — **YEH COURSE** — agent loops, OpenAI Agents SDK, MCP, autonomous agents.
6. **AI Engineer Production Track** — LLMs/agents ko AWS, GCP, Azure par scale par deploy karna — resiliency, observability, security ke saath.

**Audience guidance:**
- Courses 1–3 → technical + non-technical dono ke liye (wide audience)
- Courses 4–5 → technical ya aspiring-technical logon ke liye
- Course 6 → already technical, ya jo 1–5 complete kar chuke hain

**Ed ka claim:** Agar tum poora program (6 courses + saare projects) complete kar lete ho, toh tum khud ko **proficient AI engineer** keh sakte ho — AI Engineer, Applied AI Engineer, FDE (Forward Deployed Engineer) jaise roles ke liye ready.

**Pro tip from Ed:** Course ki **last lecture ek document hai** (Bonus Lecture — Your Exclusive Links) jisme saare courses ka summary + special discount links hain, sirf existing students ke liye.
