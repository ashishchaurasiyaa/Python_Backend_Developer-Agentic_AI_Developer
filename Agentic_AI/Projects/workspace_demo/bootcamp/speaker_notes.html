11
3 Specialist Agents — Model Selection (NEW)
4 min
Open with "project3 mein 3 agents hain — aur teeno alag-alag models use karte hain. Kyun? Cost aur quality trade-off."
Business thinking Decision making
  • Security → Opus ($0.08): "CRITICAL issue miss karna = disaster. Sabse capable model. Cost justify hai."
  • Perf → Sonnet ($0.02): "Pattern matching — N+1, sync-in-async. Sonnet kafi hai."
  • Style → Haiku ($0.001): "PEP8 check karna — cheapest task. 80x cheaper than Opus."
  • "Total per PR: ~$0.10. Workspace ke bina yeh choices hamesha manually likhni padti."
Engage "Koi sochega — Opus kyun security ke liye hi? Because a missed SQL injection costs more than $0.10. Simple ROI."

13
Progressive Disclosure (NEW)
3 min
Open with "50 skills hain — context window chhota hai. Sab ek saath load karo toh model slow ho jaata hai. Solution: progressive disclosure."
Systems thinking Simplification
  • Level 1 — Always loaded: Sirf name + description. Tiny. 200 skills = no bloat.
  • Level 2 — On trigger: Description match hone par full SKILL.md load.
  • Level 3 — On demand: Reference docs sirf tab load jab Claude open kare.
Analogy to use "Library mein jaate ho — sab books ek saath nahi padhte. Pehle title dekhte ho, phir summary, phir full book. Yahi hai progressive disclosure."
Next: "Commands — quick one-shot triggers."

16
Agent vs Skill vs MCP
2 min
Open with "Simple decision tree — tino ke liye ek line each."
  • Agent = isolation chahiye, alag model chahiye, heavy work.
  • Skill = repeatable procedure, package karna hai, reuse karna hai.
  • MCP = bahar jaana hai — DB, GitHub, web.
  • "Compose karte hain — ek skill agent ke andar chal sakti hai, agent MCP use kar sakta hai."

19
Practical — Buggy Code Review (NEW)
4 min
Open with "Main ek sawaal puchta hun — yeh code hai, 56 lines. Bina workspace ke PR review mein kitne bugs milte? Honestly?"
Practical thinking Audience challenge
  • "3 agents — Security (Opus), Perf (Sonnet), Style (Haiku) — parallel run hue."
  • Security: CRITICAL — hardcoded API key (line 9), SQL injection (line 14), pickle.loads (line 19).
  • Perf: N+1 query, sync-in-async (requests.get inside async), repeated len() in loop.
  • Style: Mutable default arg, unclear names, missing type hints, == None.
  • "Decision: human_review — kyunki CRITICAL issues mili. Merge block."
  • "Total cost: $0.10. Total time: automatic."
Ask the audience: "Haath uthao — kitno ne SQL injection wala manually pakda hota?" (wait) "Agents se miss nahi hota. Yahi point hai."

24
Q&A / Close
5 min
Open with "Shukriya. Repo mein sab kuch hai — README, WORKSPACE_GUIDE, LAB, CHEATSHEET. Koi bhi sawaal?"
Handling questions Confidence Closing strong
  • For every question: pause, repeat the question back, then answer.
  • "Achha sawaal hai" — aur phir answer. Shows respect and confidence.
3 tough questions + answers
  • "ChatGPT / Copilot se alag kyun?" — Project-level awareness + scoped tools + runs commands + git mein committed. ChatGPT har session mein nayi hai. Workspace nahi bhoolti.
  • "Mera code Anthropic ko jaata hai?" — Apni org ki data policy follow karo. Sensitive paths ke liye deny rules lagao settings.json mein.
  • "Lock-in toh nahi hoga?" — Sirf markdown aur JSON. .claude/ folder delete karo — plain project. Koi vendor lock-in nahi.
Closing line "Go build one. Sirf ek project pick karo, ek CLAUDE.md likhо, ek agent add karo. Baaki khud ho jaata hai."
