## 🧭 WHAT THIS CHANGES ABOUT YOUR PREP (concrete deltas)

1. **RAG + LangChain/LangGraph = table stakes, not differentiator.** ~65% of Track B JDs assume you can build a RAG pipeline and use LangGraph. Your [JULY_SPRINT.md](JULY_SPRINT.md) Week 2 (5-11 Jul) timing is correct — don't skip it, don't rush it either.
2. **MCP deserves its own dedicated block**, not a shared day with LangGraph — see above.
3. **"Agentic AI Engineer" postings vary wildly by seniority.** Junior/mid ones (PwC Associate, DocuSign, H2O.ai) want hands-on LangChain+RAG+prompt engineering. Senior/architect ones (UnitedHealth Lead, ZF, Hartford, Accenture) want agent evaluation frameworks, HITL design, AI governance, and multi-model routing — that's a distinct, harder layer. Given your target level (3-5 yrs per [INTERVIEW_PREP_COMPANIES.md](INTERVIEW_PREP_COMPANIES.md)), aim for the mid-tier bar first; architect-level asks (ZF, Hartford) are aspirational, not blocking.
4. **Django is not dead.** 24/47 JDs still want Django/DRF even in 2026 GenAI postings (Deloitte, Fractal, PwC, Citi, Zimperium all pair Django with AI work). Your Infosys ORM prep stays fully relevant.
5. **Evaluation/observability for AI (hallucination detection, RAGAS, guardrails) shows up more than expected** (14/47) — this is thin coverage in most self-taught GenAI paths. [`09_ragas_evaluation.md`](Agentic_AI/Level5_RAG_Vector_Databases/09_ragas_evaluation.md) and [`10_agent_evaluation.md`](Agentic_AI/Level6_Agent_Patterns/10_agent_evaluation.md) are worth more time than a first pass would suggest.
6. **One capstone project should visibly demonstrate: FastAPI/Django backend + RAG + LangGraph agent + MCP tool + basic eval.** That combination alone would speak to the majority of these 47 JDs in one story. Your existing [`project3_multiagent_code_review_starter`](Agentic_AI/Projects/project3_multiagent_code_review_starter) is close — check it has an MCP-exposed tool and an eval step, or add both.
7. **Two smaller gaps found and filled**: Semantic Kernel (named by UnitedHealth Lead Architect, ZF, Dassault Systèmes as a LangChain alternative in Azure-heavy shops) → [`09_semantic_kernel.md`](Agentic_AI/Level7_Frameworks/09_semantic_kernel.md). Databricks/Spark/Snowflake vocabulary (the data plane behind HPE, Warner Bros Discovery, Mastercard, Hartford, ZF's AI work) → [`11_databricks_spark_snowflake.md`](Agentic_AI/Level8_Production_LLMOps/11_databricks_spark_snowflake.md). Both are fluency-level, not deep-dive — low priority relative to your actual target roles.
