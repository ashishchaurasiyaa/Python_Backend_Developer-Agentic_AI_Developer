# 📚 Advanced Vocabulary — sophisticated words & collocations

Senior interviews mein aapki *vocabulary* hi aapko "junior bolne wala" se "senior sochne wala" mein badalti hai. Yeh file 150+ high-level words, precise verbs, aur collocations ke saath hai — saare technical aur professional context mein. Roz 10-15 words bolo, sentence banao, aur slowly inhe apni natural speech mein utaaro.

> Tip: Bada shabd bolna goal *nahi* hai. Goal hai — **sahi shabd, sahi jagah, naturally**. Ek "robust solution" bolna "very good solution" se 10x professional lagta hai.

## 4. ⚡ Precise Verbs (replace weak verbs)

Indians often "do", "make", "good", "very" pe atak jaate hain. Yeh precise verbs aapko sharp banate hain.

| Weak / vague | Precise replacement | Example |
|--------------|--------------------|---------|
| make better | **enhance / improve / optimise** | We **optimised** the query. |
| make smaller | **reduce / minimise / shrink** | We **reduced** latency by 40%. |
| make sure | **ensure / verify / guarantee** | **Ensure** the config is correct. |
| find out | **identify / determine / uncover** | We **identified** the bottleneck. |
| fix | **resolve / address / remediate** | We **resolved** the issue. |
| use | **leverage / utilise / employ** | We **leveraged** caching. |
| do a test | **conduct / run / perform a test** | We **conducted** load testing. |
| make a decision | **reach / arrive at a decision** | We **reached** a decision. |
| show | **demonstrate / illustrate / highlight** | The graph **demonstrates** the trend. |
| get | **obtain / acquire / retrieve** | We **retrieve** data from the cache. |
| start | **initiate / launch / kick off** | We **initiated** the rollout. |
| stop | **halt / suspend / terminate** | We **halted** the deployment. |
| change | **modify / adjust / revise** | We **revised** the estimate. |
| help | **assist / support / aid** | This tool **assists** debugging. |
| think about | **consider / contemplate / weigh** | Let's **weigh** the options. |

> ❌ "We did a big improvement and it became very good."
> ✅ "We made a **significant** improvement and the result was **excellent / impressive**."

## 5. 🧷 Collocations — THE big one (yahan Indians slip karte hain)

**Collocation** = woh words jo English mein *naturally saath* aate hain. Inka koi logical rule nahi — bas yahi natural lagta hai. "Do a mistake" grammatically samajh aata hai par **galat** hai; sahi hai "**make** a mistake". Native speakers turant pakad lete hain.

### Why "do a mistake" ❌ → "make a mistake" ✅

English mein:
- **make** = create / produce (kuch naya banana — often abstract): make a decision, make a mistake, make progress.
- **do** = perform / carry out (ek activity karna): do the work, do research, do a favour.

Mistake ek cheez hai jo aap *create / produce* karte ho (intend nahi karte par ban jaati hai) — isliye **make**. Yeh logic se zyada *aadat* se aata hai, isliye table yaad karo aur bolo.

### MAKE + noun

| Collocation | Hindi | Example |
|-------------|-------|---------|
| make a mistake | galti karna | I **made a mistake** in the config. |
| make a decision | faisla lena | We **made a decision** to ship. |
| make progress | pragati karna | We're **making progress** on the bug. |
| make an effort | koshish karna | Please **make an effort** to write tests. |
| make sense | samajh aana | This design **makes sense**. |
| make a suggestion | sujhaav dena | Can I **make a suggestion**? |
| make an exception | apvaad karna | We **made an exception** this time. |
| make an impact | asar daalna | This feature **made an impact**. |
| make a difference | farq laana | Good docs **make a difference**. |
| make a point | baat rakhna | He **made a valid point**. |

### DO + noun

| Collocation | Hindi | Example |
|-------------|-------|---------|
| do the work | kaam karna | Let's **do the work** properly. |
| do research | shodh karna | We **did research** on the options. |
| do a favour | ehsaan karna | **Do me a favour** and review this. |
| do business | vyapaar karna | We **do business** with that vendor. |
| do your best | poori koshish | I'll **do my best**. |
| do harm / damage | nuksaan karna | The bug **did damage** to the data. |
| do a task | kaam karna | I'll **do this task** today. |
| do an analysis | vishleshan karna | We **did an analysis** of the logs. |

### TAKE + noun

| Collocation | Hindi | Example |
|-------------|-------|---------|
| take a decision | faisla lena (UK-ish; "make" safer) | We need to **take action**. |
| take responsibility | zimmedari lena | I **take responsibility** for the bug. |
| take a break | break lena | Let's **take a short break**. |
| take a risk | jokhim uthana | We **took a calculated risk**. |
| take into account | dhyaan mein rakhna | **Take** scale **into account**. |
| take advantage of | faayda uthana | We **took advantage of** the cache. |
| take ownership | zimmedari uthana | Seniors **take ownership**. |
| take a look | dekhna | **Take a look** at this PR. |
| take notes | notes lena | I **took notes** during the call. |
| take time | samay lagna | Quality **takes time**. |

### HAVE + noun

| Collocation | Hindi | Example |
|-------------|-------|---------|
| have a conversation | baat-cheet karna | Let's **have a conversation** about scope. |
| have an impact | asar hona | This will **have an impact** on latency. |
| have access (to) | pahunch hona | Do you **have access to** prod? |
| have a meeting | meeting karna | We **have a meeting** at 3. |
| have a look | dekhna | Can you **have a look**? |
| have an idea | vichaar hona | I **have an idea** for the fix. |
| have an issue | samasya hona | We **have an issue** with the queue. |
| have a deadline | deadline hona | We **have a tight deadline**. |

> ❌ Common slips: "do a mistake", "take a photo" is fine but "do a decision" ❌, "make a research" ❌, "do a meeting" ❌, "give a exam" ❌ (→ "take an exam").
> ✅ make a decision, do research, have/hold a meeting, take an exam.

## 7. 🚀 Tech-Leadership Vocabulary

Yeh words system design interviews aur architecture discussions ka *core* hai. Inhe fluently bolna aapko credible banata hai.

| English | Hindi meaning | Example sentence |
|---------|--------------|------------------|
| scalability | badhne ki kshamta | We designed for horizontal **scalability**. |
| trade-off | ek cheez ke liye doosri chhodna | It's a **trade-off** between latency and cost. |
| bottleneck | rukawat, jahan slow ho | The database is the **bottleneck**. |
| mitigate | kam karna (risk) | We **mitigated** the risk with retries. |
| throughput | kitna kaam per second | We doubled the **throughput**. |
| latency | response mein laga time | We reduced **latency** to under 100 ms. |
| resilient | jhatka jhel le | The system is **resilient** to failures. |
| fault-tolerant | kharaabi sehne wala | We built a **fault-tolerant** pipeline. |
| idempotent | baar-baar same result | Make the endpoint **idempotent**. |
| eventual consistency | thodi der baad consistent | We accept **eventual consistency** here. |
| provision | resources allot karna | We **provisioned** more instances. |
| decouple | alag karna (dependency) | We **decoupled** the services. |
| instrument | metrics jodna | We **instrumented** the code for tracing. |
| degrade gracefully | dheere fail hona | The app **degrades gracefully** under load. |
| single point of failure | ek hi fail point | We eliminated the **single point of failure**. |
| technical debt | shortcut ka karz | We're paying down **technical debt**. |
| observability | system ko dekh paana | Good **observability** speeds up debugging. |
| backpressure | overload control | The queue applies **backpressure**. |
| concurrency | ek saath kayi cheezein | We handle high **concurrency**. |
| sharding | data ko baant-na | We use **sharding** to scale the DB. |

> Interview gold sentence:
> "There's always a **trade-off** — optimising for **throughput** can increase **latency**, so we **mitigate** that with caching and design for **graceful degradation** under load."

## 🎤 Practice (zor se bolo)

Inhe zor se bolo, aur har sentence mein highlighted word ka *sahi pronunciation* aur *sahi collocation* check karo.

1. "We **evaluated** several options and **reached a decision** to use a **resilient**, **scalable** design."
2. "I **made a mistake** in the config, but we **made progress** quickly after we **identified** the **bottleneck**."
3. "Let's **take a calculated risk**, but first **take** scale **into account** and **mitigate** the obvious failure points."
4. "I **spearheaded** the migration, **mentored** two juniors, and **own** the service end-to-end."
5. "This is a **nuanced trade-off** between **latency** and cost; the **elegant** solution isn't always the **pragmatic** one."
6. "We **conducted** load testing, **instrumented** the code, and improved **throughput** by 40%."
7. "Can I **make a suggestion**? Let's **streamline** the pipeline and **reduce** the **redundant** API calls."
8. "I **take responsibility** for the incident; we lacked **observability**, so we **couldn't discern** the root cause quickly."
9. "The legacy code is **brittle** and **convoluted**; we should **rationalise** the services and pay down **technical debt**."
10. "We aligned all **stakeholders**, hit the **milestone**, and delivered a **seamless** experience."
11. Replace the weak word out loud: "We did a big improvement" → "We **made a significant improvement**." / "We made a research" → "We **did research**."
12. "The endpoint must be **idempotent** and **fault-tolerant** so the system **degrades gracefully** under high **concurrency**."
