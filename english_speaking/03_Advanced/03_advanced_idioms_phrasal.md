# 🎯 Advanced Idioms & Phrasal Verbs — natural, fluent speech

Idioms aur phrasal verbs hi woh cheez hai jo aapki English ko "textbook" se "native-like" banati hai. Senior engineers aur managers inhe constantly use karte hain — standups, planning, retros mein. Yeh file 40+ professional idioms + 40+ phrasal verbs deti hai, har ek mein note ki **interview-safe** hai ya **too casual**. Galat jagah casual idiom bolna risky hai, isliye dhyaan se.

> Golden rule: ek idiom *naturally* aaye toh hi bolo. Force mat karo. Ek galat-jagah idiom 5 sahi idioms se zyada noticeable hota hai.

## Part B — 🔧 Professional Phrasal Verbs (40+)

Phrasal verb = verb + particle (up, out, in, on...) jiska matlab badal jaata hai. Yeh native speech ka backbone hain. Table: `Phrasal verb | Meaning (Hindi) | Example`.

### Building, shipping, scaling

| Phrasal verb | Meaning (Hindi) | Example | Safe? |
|--------------|----------------|---------|-------|
| roll out | launch/release karna dheere-dheere | We'll **roll out** the feature to 10% first. | ✅ Safe |
| scale up | badhana (capacity) | We **scaled up** during the sale. | ✅ Safe |
| scale down | ghatana | We **scaled down** after the peak. | ✅ Safe |
| spin up | jaldi se start karna (server) | Let's **spin up** a new instance. | ✅ Safe |
| set up | install/configure karna | I **set up** the CI pipeline. | ✅ Safe |
| build out | poora develop karna | We **built out** the admin panel. | ✅ Safe |
| ship out | bhej dena, deliver | We **shipped out** the release on time. | ✅ Safe |
| ramp up | tezi se badhana | We **ramped up** hiring this quarter. | ✅ Safe |
| phase out | dheere-dheere hatana | We're **phasing out** the old API. | ✅ Safe |
| roll back | wapas pichli state mein | We had to **roll back** the deploy. | ✅ Safe |

### Planning & managing

| Phrasal verb | Meaning (Hindi) | Example | Safe? |
|--------------|----------------|---------|-------|
| carry out | execute karna | We **carried out** the migration. | ✅ Safe |
| map out | plan banana | Let's **map out** the next sprint. | ✅ Safe |
| break down | tukdon mein baant-na | We **broke down** the epic into tasks. | ✅ Safe |
| lay out | clearly samjhana | He **laid out** the architecture. | ✅ Safe |
| account for | wajah/jagah dena | We must **account for** edge cases. | ✅ Safe |
| cut down (on) | kam karna | We **cut down on** API calls. | ✅ Safe |
| keep up with | saath banaye rakhna | It's hard to **keep up with** the load. | ✅ Safe |
| catch up (on) | piche ka pura karna | I need to **catch up on** the PRs. | ✅ Safe |
| wrap up | khatam karna | Let's **wrap up** this meeting. | ✅ Safe |
| kick off | shuru karna | We **kicked off** the project Monday. | ✅ Safe |

> ❌ Common mistakes:
> - "I will **revert** to you" (Indian-English for "reply") → ✅ "I will **get back to** you." (revert ka matlab "undo/roll back" hai, reply nahi!)
> - "Please **do the needful**" → ⚠️ very Indian-English, avoid in interviews → ✅ "Please **take care of** it" / "Please **handle** it."
> - "**Prepone** the meeting" → not standard English → ✅ "**Move up** / **bring forward** the meeting."
> - "I will **intimate** you" → ✅ "I will **let you know** / **inform** you / **notify** you."

## 🎤 Practice (zor se bolo)

Inhe zor se bolo, *natural rhythm* ke saath. Phir niche wala personal task karo — wahi asli practice hai.

1. "Let's **touch base** tomorrow and make sure we're all **on the same page**."
2. "That's **low-hanging fruit** — let's **knock it out** first, then **circle back** to the harder parts." *(circle back = wapas aana)*
3. "We had to **roll back** the deploy and go **back to the drawing board**."
4. "Let me **loop in** the security team and **run** the design **by** them before we **sign off**."
5. "I'll **dig into** the logs, **drill down** on the slow query, and **track down** the root cause."
6. "We **scaled up** during the sale, **ironed out** a few issues, and **rolled out** the feature smoothly."
7. "Tech debt is **the elephant in the room**; if we keep **cutting corners**, it'll become **a ticking time bomb**."
8. "I'll **follow up** with the client and **get back to you** by EOD." *(NOT "revert to you"!)*
9. "Let's **map out** the sprint, **break down** the epic, and **factor in** the migration cost."
10. "The new hire **hit the ground running** and got **up to speed** in two days."
11. "Good test coverage **pays dividends** later, even if it doesn't **move the needle** today."
12. "Let's **wrap up** here; I don't want to get **in the weeds** on implementation details." *(in the weeds = casual, use carefully)*

**Mini speaking task (90 seconds):**
Apne current ya pichle kaam ke baare mein 4-5 sentences bolo aur **2-3 idioms/phrasal verbs naturally** use karo — *forced nahi*. Example structure:
"In my last project, I **spearheaded** a migration. We **kicked it off**, **broke down** the work, and **rolled it out** gradually. Tech debt was **the elephant in the room**, so we **bit the bullet** and rebuilt the core **from the ground up**."

Record karo aur 2 cheezein check karo: (1) koi idiom **galat-jagah / too casual** toh nahi tha interview-context ke liye? (2) koi **Indian-English** slip (revert/do the needful/prepone/intimate) toh nahi aaya?
