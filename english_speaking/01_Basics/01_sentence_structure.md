# 🧱 Sentence Structure — English vaakya kaise banta hai

Is lesson mein hum samjhenge ki English ka ek saaf, sahi sentence kaise banta hai — bilkul foundation se, taaki bolte waqt confidence aaye.

## 🎯 Sentence kya hota hai?

Ek **sentence** ek complete soch (complete thought) hota hai. Usmein kam-se-kam ek **subject** (kaun) aur ek **verb** (kya kar raha hai) hona zaroori hai.

- "Go." — chhota sentence (command), subject "you" chhupa hua hai.
- "I work." — subject (I) + verb (work). Complete thought.
- "Backend" — ye sentence NAHI hai, sirf ek word hai. Adhuri baat.

Yaad rakho: har English sentence **capital letter** se shuru hota hai aur **full stop (.)**, question mark (?), ya exclamation mark (!) pe khatam hota hai.

## 🔑 Subject + Verb + Object (SVO) — sabse important rule

English ka core pattern hai: **Subject → Verb → Object**.

| Subject (kaun) | Verb (kaam) | Object (kisko/kya) |
|---|---|---|
| I | eat | food |
| She | writes | code |
| We | use | Python |
| They | deploy | the app |

### Hindi SOV hai, English SVO hai — yahi sabse badi galti ki jagah hai

Hindi mein verb (kaam) hamesha END mein aata hai. English mein verb BEECH mein aata hai (subject ke turant baad).

| Hindi (SOV) | Word-by-word | Correct English (SVO) |
|---|---|---|
| Main khana khata hoon | I food eat | **I eat food** |
| Wah code likhti hai | She code writes | **She writes code** |
| Hum chai peete hain | We tea drink | **We drink tea** |
| Mujhe English aati hai | Me English comes | **I know English** |
| Woh bug fix karta hai | He bug fixes | **He fixes the bug** |

> ❌ Common mistake: "I food eat" / "She code writes" (Hindi word order English mein ghusa diya)
> ✅ Correct: "I eat food" / "She writes code" — verb subject ke turant baad rakho.

Dimaag mein ek line bitha lo: **English mein pehle bolo KAUN, phir KYA KAR RAHA HAI, phir KISKE SAATH/KISKO.**

## 🧩 Sentence ke 4 types

English mein chaar tarah ke sentences hote hain:

### 1. Statement (kathan) — koi baat batana
Ek normal jaankari deta hai. Full stop (.) se khatam.
- I am a backend developer.
- We use a microservices architecture.

### 2. Question (prashn) — kuch poochhna
Question mark (?) se khatam.
- Are you a developer?
- What is your experience?

### 3. Command / Request (aadesh ya nivedan)
Kisi ko kuch karne ko kehna. Subject "you" chhupa hota hai.
- Open the file.
- Please review my code.

### 4. Exclamation (aashcharya / josh) — strong feeling
Exclamation mark (!) se khatam.
- That's amazing!
- We shipped it!

## ➕➖❓ Positive, Negative aur Question forms

Ek hi baat ko teen tarah se bola ja sakta hai. Ye pattern interview mein bahut kaam aata hai.

| Form | Example |
|---|---|
| Positive (haan-waala) | I **work** at a startup. |
| Negative (nahi-waala) | I **do not work** at a startup. |
| Question (sawaal) | **Do** you work at a startup? |

Aur "be-verb" (am/is/are) ke saath:

| Form | Example |
|---|---|
| Positive | She **is** a developer. |
| Negative | She **is not** a developer. |
| Question | **Is** she a developer? |

> ❌ Common mistake: "I am not work here" / "She not is a developer."
> ✅ Correct: "I do not work here." / "She is not a developer." — action verb ke saath **do/does not**, be-verb ke saath seedha **not**.

## 🔤 Capitalization aur full stops

Chhoti cheezein, par professional English mein bahut maayne rakhti hain:

- Har sentence **capital letter** se shuru: ~~i am ready~~ → **I am ready.**
- Word **"I"** hamesha capital, sentence mein kahin bhi ho: "Yesterday I fixed it."
- Logon ke naam, sheher, company, din, mahine — sab capital: **Monday**, **India**, **Google**, **March**.
- Statement → full stop (.), question → (?), exclamation → (!).

> ❌ Common mistake: "i think i can do it" (chhota i)
> ✅ Correct: "I think I can do it."

## 🏗️ 2 word se lambe sentence tak — step by step

Sentence ko bricks ki tarah banao. Pehle chhota, phir detail add karo.

| Step | Sentence |
|---|---|
| 2 words | I work. |
| + object | I write code. |
| + adjective | I write clean code. |
| + place | I write clean code at the office. |
| + time | Every day I write clean code at the office. |

Ek aur example:

| Step | Sentence |
|---|---|
| 2 words | She tests. |
| + object | She tests the API. |
| + how | She tests the API carefully. |
| + when | She tests the API carefully before release. |

Bolte waqt confidence ke liye: **pehle short sentence bolo**, agar comfortable ho to detail add karo. Lamba galat sentence se chhota sahi sentence behtar hai.

## ✅ Quick recap

- English = **SVO** (Subject-Verb-Object). Verb beech mein, end mein nahi.
- 4 types: statement, question, command, exclamation.
- Negatives/questions: action verb ke saath **do/does**, be-verb seedha.
- Capital letter se shuru, sahi punctuation se khatam.
- Chhote sentence se shuru karo, dheere-dheere bada karo.

## 🎤 Practice (zor se bolo)

Neeche diye sentences ZOR SE, saaf bolkar abhyaas karo. Har ek kam-se-kam 2 baar.

1. I write code every day.
2. She tests the API before release.
3. We use Python and PostgreSQL at work.
4. They deploy the application on Friday.
5. Do you work in the backend team?
6. Is he a senior developer?
7. I do not understand this error yet.
8. Please review my pull request.
9. We shipped the feature today!
10. Every morning I read my emails and plan my day.

Ab in Hindi sentences ko English mein bolo (pehle bina dekhe try karo, phir check karo):
11. "Main roz code likhta hoon." → *I write code every day.*
12. "Woh bug fix karti hai." → *She fixes the bug.*
