# 📋 Engineering Practices (Year 3-4)

> **Mid-Level Engineering Skills** — process, leadership readiness, production maturity.

## Target Audience

- **3-4 YOE Backend Developers**
- Looking to transition to Senior
- Mid-level promotion candidates

## Files in This Phase

| # | File | Topic |
|---|------|-------|
| 01 | `01_code_review_skills.md` | Giving & receiving code reviews |
| 02 | `02_sprint_planning_estimation.md` | Agile, Scrum, story points |
| 03 | `03_incident_response_runbooks.md` | Production incidents, on-call |
| 04 | `04_post_mortem_writing.md` | Blameless post-mortems |
| 05 | `05_architecture_decision_records.md` | ADRs for decisions |
| 06 | `06_tech_debt_management.md` | Tracking and paying down debt |

## How to Use

1. Read in order (1-6)
2. Apply on next sprint
3. Discuss with team
4. Refine your practices

## Style

All files: **Hinglish / Bhai mode** with:
- WHAT (definition)
- WHY (motivation)
- HOW (mechanism with architecture)
- Real examples
- Common mistakes
- Q&A

**No code solutions** — pure conceptual understanding.

## Estimated Time

- Per file: 30-45 min
- Total: ~3-4 hours
- Practice over weeks to internalize
