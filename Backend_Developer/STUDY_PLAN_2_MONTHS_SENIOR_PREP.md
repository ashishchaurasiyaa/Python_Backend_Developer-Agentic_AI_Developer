## System Design Framework (Practice This)

```
1. CLARIFY (5 min)
   ✓ What features? Scale? Users?
   ✓ Constraints: latency, consistency, availability
   ✓ Read vs write ratio

2. ESTIMATE (5 min)
   ✓ Users (DAU/MAU)
   ✓ QPS (peak vs avg)
   ✓ Storage (per user, per object)
   ✓ Bandwidth

3. APIs (5 min)
   ✓ Define core endpoints
   ✓ Request / response shapes

4. SCHEMA (5 min)
   ✓ Tables / collections
   ✓ Indexes
   ✓ Sharding key (if needed)

5. HIGH-LEVEL DESIGN (10 min)
   ✓ Components (LB, app, cache, DB, queue)
   ✓ Draw boxes + arrows
   ✓ Justify each choice

6. DEEP DIVE (10 min)
   ✓ Pick 1-2 critical components
   ✓ Algorithm / data structure choice
   ✓ Trade-offs

7. SCALE (5 min)
   ✓ Bottlenecks at 10x
   ✓ Caching strategy
   ✓ Sharding strategy
   ✓ Multi-region considerations

8. FAILURE MODES (3 min)
   ✓ What breaks?
   ✓ Graceful degradation

9. TRADE-OFFS (2 min)
   ✓ CAP choices made
   ✓ What we sacrificed
```

## Behavioral Story Drilling

Practice these STAR-format stories DAILY (15 min each):

```
1. "Tell me about a time you led a project"
   → Situation, Task, Action, Result format
   → 90-120 second answer

2. "Describe a technical challenge you solved"
   → Specific problem, your approach, trade-offs
   → Quantify the impact

3. "A time you disagreed with a teammate"
   → Show maturity + collaboration
   → Resolution focused

4. "Biggest failure / mistake"
   → Be honest, show learning
   → Don't blame others

5. "Why are you leaving current company?"
   → Frame positively (growth, scale, learning)
   → NEVER badmouth

6. "Why do you want this role?"
   → Specific to company (do research!)
   → Connect to your goals

7. "Where do you see yourself in 3 years?"
   → Show ambition + alignment

8. "Most complex system you've designed"
   → 2-3 minute structured answer
   → Architecture diagram in your head

9. "Time you mentored someone"
   → Senior signal
   → Specific example

10. "A time you pushed back on requirements"
    → Show judgment + communication
```

### Practice Method

```
1. Write each story in STAR format (1 page max)
2. Record yourself telling it (60-90 sec)
3. Watch back — note: filler words, pace, clarity
4. Refine
5. Re-record
6. Repeat until each story is FLUENT, not memorized
```

**Reference:** [03_Interview_AnyYear/02_Interview_Prep/12_negotiation_offer.md](03_Interview_AnyYear/02_Interview_Prep/12_negotiation_offer.md)

### Key Tactics

```
1. NEVER give first number
   ✓ "I'm looking for market-competitive comp"
   ✓ Get THEIR range first

2. STACK rank offers
   ✓ Have 2-3 competing offers
   ✓ Reference (carefully) without sharing specifics

3. NEGOTIATE BEYOND BASE
   ✓ Joining bonus
   ✓ ESOPs / RSUs
   ✓ Vesting cliff (4-year standard)
   ✓ Relocation
   ✓ WFH flexibility
   ✓ Sign-on milestones

4. THINK TOTAL COMPENSATION
   Total = Base + Bonus + Stock + Other

5. SLEEP ON IT
   ✓ Never accept on the call
   ✓ "Can I get back to you in 48 hours?"
   ✓ Talk to mentors / family
```

### Sample Negotiation

```
Recruiter: "We're offering ₹28 LPA base + 5L joining"
You:       "Thanks! I'm in final stages with 2 other companies

You:       "Mid-30s range total. Is there flexibility?"

You:       "Appreciate that. I'd also like to discuss:
```
